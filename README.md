# Week1Task27 — Локальный LLM-чат (веб-приложение)

Веб-приложение, которое общается с **локальной** LLM через сервер **Ollama**
(OpenAI-совместимый эндпоинт `http://localhost:11434/v1`) и поддерживает
стриминг ответов (SSE), историю диалога и набор команд.

Работает полностью офлайн — облачные модели не используются.

---

## Возможности

- 💬 Чат с локальной моделью, ответ печатается «живьём» (SSE-стриминг).
- 🧠 Селектор модели (список подгружается из Ollama), по умолчанию `gpt-oss:20b`.
- 🟢 Индикатор статуса: доступность Ollama, текущая модель, число сообщений, аптайм.
- ⌨️ Команды вводятся прямо в поле чата (начинаются с `/`) и обрабатываются на бэкенде.
- 📦 Единый **реестр команд** — из него формируются и `/help`, и обработка.
- 🗑️ Кнопки «Очистить чат» и «Экспорт» (скачивание истории в JSON).
- 🧯 Понятные сообщения об ошибках на русском (Ollama недоступна, модель не найдена, таймаут, контекст).
- 📝 Логирование в `logs/app.log` и в консоль.

## Стек

| Слой | Технология |
|---|---|
| Фронтенд | HTML + CSS + Vanilla JS (без фреймворков) |
| Бэкенд | Python 3.14 + FastAPI + Uvicorn |
| Обращение к LLM | библиотека `openai` (base_url → Ollama `/v1`) + `httpx2` для нативных вызовов `/api/*` |

## Команды (вводятся в поле чата)

| Команда | Описание |
|---|---|
| `/help` | Список команд (формируется из реестра) |
| `/clear` | Очистить историю диалога |
| `/models` | Показать список моделей Ollama с пометкой текущей |
| `/model <имя>` | Переключить модель; предыдущая выгружается из VRAM |
| `/unload` | Выгрузить текущую модель из памяти Ollama |
| `/system` | Показать текущий системный промпт |
| `/system <текст>` | Задать новый системный промпт |
| `/status` | Текущая модель, размер истории, доступность Ollama, аптайм |
| `/export` | Скачать историю диалога в JSON |
| `/reset` | Сброс к дефолтам (пустая история, `gpt-oss:20b`, исходный промпт) |
| `/ping` | Тестовая команда (демонстрирует, что `/help` берётся из реестра) |

> Чтобы добавить команду — зарегистрируйте `CommandSpec` в `app/commands.py`
> (см. функцию `_register_default_commands()`); она сразу появится в `/help`.

## API-эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | Веб-интерфейс |
| GET | `/api/status` | Доступность Ollama, модель, размер истории, аптайм |
| GET | `/api/models` | Список моделей Ollama + текущая |
| POST | `/api/model` | `{ "name": "<модель>" }` — переключение + выгрузка старой |
| POST | `/api/unload` | Выгрузка текущей модели |
| GET | `/api/system` | Текущий системный промпт |
| POST | `/api/system` | `{ "prompt": "<текст>" }` — новый промпт |
| POST | `/api/chat` | `{ "message": "...", "stream": true }` — SSE-поток (или JSON при `stream=false`) |
| POST | `/api/clear` | Очистка истории |
| POST | `/api/reset` | Полный сброс к дефолтам |
| GET | `/api/export` | JSON с историей (файл на скачивание) |
| GET | `/api/help` | Справка по командам из реестра |

Формат SSE-событий:
```
data: {"type": "token", "content": "..."}          # фрагмент ответа
data: {"type": "done", "model": "...", "history_length": N, "data": {...}}
data: {"type": "error", "message": "<текст на русском>"}
```

## Обработка ошибок

| Ситуация | Сообщение |
|---|---|
| Ollama недоступна | «Локальный сервер Ollama не запущен. Запустите C:\LLM\Ollama\ollama.exe serve» |
| Модель не найдена | «Модель <имя> не найдена. Доступные: …» |
| Таймаут | «Запрос превысил время ожидания…» |
| Превышен контекст | подсказка увеличить `num_ctx` / очистить историю |
| Прочее | текст ошибки без трейсбэка (трейсбэк — в `logs/app.log`) |

## Заметки по окружению

- Python **3.14.7**: `openai` 3.27 опирается на HTTP-клиент **`httpx2`**
  (модуль `httpx2`, API совместим с `httpx`); он импортируется как `httpx`.
- Модель по умолчанию и системный промпт задаются в `app/config.py` и могут быть
  переопределены переменными окружения (`DEFAULT_MODEL`, `OLLAMA_BASE_URL`, `APP_PORT` и т.д.).
